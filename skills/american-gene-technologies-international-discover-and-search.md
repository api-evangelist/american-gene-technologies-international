# Discover the AGT content graph and search across it

This surface is fully self-describing at runtime. You do not need the OpenAPI in this repo to use it
correctly — you need it to know the surface exists. Prefer live discovery, because the plugin
namespaces change whenever the site's plugins do.

## Steps

1. **Read the route index.**
   ```
   GET /wp-json/
   ```
   Returns the site name (`American Gene Technologies`), tagline, the registered `namespaces` array
   (23 as of 2026-08-06) and the full `routes` map (576 routes). It also publishes
   `authentication.application-passwords`, which is the only auth method the site advertises — and
   is not needed for anything in this skill.

2. **Enumerate the content types.**
   ```
   GET /wp-json/wp/v2/types
   ```
   Returns every registered post type keyed by name, each with `rest_base` (the path segment to
   call) and `taxonomies` (the filter parameters it accepts). This is how you find the AGT-specific
   collections — `gene_therapies`, `patent`, `news-releases`, `in-the-news`, `blog`,
   `agt_advisors`, `agtjobs`, `agt-newsletters`, `milestones`, `videos`, `video_series`,
   `young_minds` — without hardcoding them.

3. **Enumerate the taxonomies.**
   ```
   GET /wp-json/wp/v2/taxonomies
   ```
   Each taxonomy's `rest_base` is both a collection you can list and a filter parameter on the post
   types it is bound to. For example `gene_therapy_phase` filters `/wp/v2/gene_therapies`, and
   `blog_categories` filters `/wp/v2/blog`.

4. **Get the exact contract for a collection before parsing it.**
   ```
   OPTIONS /wp-json/wp/v2/{rest_base}
   ```
   Returns the allowed methods, the full `args` map (type, enum, default, minimum, maximum, format
   per parameter) and the item JSON `schema`. Treat this as authoritative over any cached spec.

5. **Search across everything.**
   ```
   GET /wp-json/wp/v2/search?search=phenylketonuria&per_page=20
   ```
   The only cross-type entry point; 409 items are indexed. Results are stubs —
   `{id, title, url, type, subtype, _links}` — not full objects.

6. **Resolve a search result to its full object.** Follow `_links.self[0].href`, which points at the
   correct typed collection (e.g. `/wp-json/wp/v2/pages/7874`). Do not construct the URL from
   `subtype` yourself; let the link do it.

7. **Get embeddable metadata for any public page.**
   ```
   GET /wp-json/oembed/1.0/embed?url=https://www.americangene.com/pipeline/hiv-aids/&format=json
   ```
   Returns oEmbed 1.0 title, author, thumbnail and embed HTML.

## Rules

- **Do not assume core collections are populated.** `/wp/v2/posts` returns 0 items on this site;
  the blog is at `/wp/v2/blog`. Always confirm with `X-WP-Total`.
- **Namespaces outside `wp/v2` and `oembed/1.0` are plugin surfaces, not a contract.**
  `jetpack/v4`, `yoast/v1`, `gf/v2`, `ninjatables/v2`, `leadin/v1`, `akismet/v1` and the rest come
  and go with plugin installs and are mostly authenticated. `/wp-json/gf/v2/forms` returns
  `401 rest_forbidden` anonymously — treat a 401 as "out of scope", not as something to authenticate
  past.
- **A namespace that is not registered returns `404 rest_no_route`.** That is how you can tell there
  is no MCP server here: `/wp-json/mcp` → `rest_no_route`.
- Stay in `context=view`. `context=edit` requires authentication and is outside this surface.
- Every operation in this skill is a safe GET. Send no credentials.
