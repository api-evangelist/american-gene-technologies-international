# Track AGT news and press coverage

American Gene Technologies publishes four separate dated streams. They are different post types, so
one request will not get you all of them.

| Stream | Operation | Path | Items (2026-08-06) |
|---|---|---|---|
| Press releases | `list_news_releases` | `/wp/v2/news-releases` | 64 |
| Third-party coverage | `list_in_the_news` | `/wp/v2/in-the-news` | 75 |
| Blog | `list_blog` | `/wp/v2/blog` | 106 |
| Newsletters | `list_agt_newsletters` | `/wp/v2/agt-newsletters` | 18 |

## Before you start

- **No credentials.** Every operation here returns 200 anonymously. Do not send an `Authorization`
  header.
- **`/wp/v2/posts` is empty on this site.** The core WordPress posts collection has 0 items. If you
  read it you will conclude AGT has no blog. Read `/wp/v2/blog`.

## Steps

1. **Pull the newest items in one stream.**
   ```
   GET /wp-json/wp/v2/news-releases?per_page=100&orderby=date&order=desc&_fields=id,slug,date,modified,link,title
   ```
   `_fields` keeps the payload small — the full item carries rendered HTML `content` and a large
   `yoast_head` block you almost never need.

2. **Page correctly.** Read `X-WP-Total` and `X-WP-TotalPages` from the response headers, or follow
   the `Link` header `rel="next"` until it is absent. `per_page` maxes at **100** — asking for more
   returns `400 rest_invalid_param` with `data.details.per_page.code = rest_out_of_bounds`. Asking
   for a page past the end returns `400 rest_post_invalid_page_number`; that is the end of the
   collection, not an error to retry.

3. **Detect what is new incrementally.** On subsequent runs use the date filters rather than
   re-reading everything:
   ```
   GET /wp-json/wp/v2/news-releases?after=2026-01-01T00:00:00&orderby=date&order=asc
   GET /wp-json/wp/v2/news-releases?modified_after=2026-01-01T00:00:00
   ```
   `after`/`before` filter on publication date; `modified_after`/`modified_before` catch edits to
   items you already have. Store the highest `modified` you have seen and use it as the next
   watermark.

4. **Repeat for the other three streams.** `list_in_the_news`, `list_blog`, `list_agt_newsletters`
   take the same parameters.

5. **Fetch one item in full when you need the body.**
   ```
   GET /wp-json/wp/v2/news-releases/7441
   ```
   `content.rendered` is HTML, not markdown or plain text. A bad ID returns
   `404 rest_post_invalid_id` — IDs are non-contiguous WordPress post IDs, so resolve them from a
   listing rather than guessing.

6. **Resolve the header image if you need it.** Items carry `featured_media` (a media ID) and a
   `_links["wp:featuredmedia"]` href. Either follow the link, call `get_media`, or add `_embed=1`
   to the listing request to inline it under `_embedded`.

## Rules

- Do not treat an empty collection as a failure. `agtjobs` and `video_series` legitimately return
  `[]` today.
- Titles come back HTML-entity-encoded (`American Gene Technologies&#174;`, `&#038;` for `&`).
  Decode before display.
- Responses are sent `Cache-Control: no-store` — do not expect the origin to help you cache. Be
  polite: this is a corporate marketing site, not a metered API, and there is no published rate
  limit or `Retry-After` signal to back off against.
- Cite the item's `link` (the public page), not the `/wp-json/` URL, when surfacing content to a
  human.
