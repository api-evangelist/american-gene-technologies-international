# Read the AGT science portfolio

American Gene Technologies registered custom WordPress post types for its science-facing content
and left them exposed over REST. This is the highest-value first-party content on the surface.

| Collection | Operation | Path | Items (2026-08-06) |
|---|---|---|---|
| Patents | `list_patent` | `/wp/v2/patent` | 53 |
| Gene therapy reference entries | `list_gene_therapies` | `/wp/v2/gene_therapies` | 4 |
| Advisory board | `list_agt_advisors` | `/wp/v2/agt_advisors` | 7 |
| Milestones | `list_milestones` | `/wp/v2/milestones` | 1 |
| Young Minds explainers | `list_young_minds` | `/wp/v2/young_minds` | 4 |

## Steps

1. **Walk the patent portfolio.**
   ```
   GET /wp-json/wp/v2/patent?per_page=100&orderby=title&order=asc&_fields=id,slug,title,link,date,featured_media
   ```
   53 items fit in one page. Titles are the patent titles as filed — e.g. *Compositions And Methods
   for Treating Phenylketonuria*, *Viral vector for treating Parkinson's disease*. Several titles
   carry a country suffix (`-jp`) in the slug indicating a national-phase filing. `content.rendered`
   on the full item carries the body AGT published for that patent; the `featured_media` ID points
   at the scanned figure or cover image, retrievable with `get_media`.

2. **Read the gene therapy reference entries and their phase.**
   ```
   GET /wp-json/wp/v2/gene_therapies?_fields=id,slug,title,link,gene_therapy_phase
   GET /wp-json/wp/v2/gene_therapy_phase
   ```
   The four entries (Zolgensma, Yescarta, Kymriah, Zynteglo) are *approved third-party* gene
   therapies AGT publishes as educational context — they are **not** AGT's own pipeline. All four
   carry term `61` = `fda-approved`. Do not report them as AGT products.

3. **For AGT's actual pipeline, read the pages, not this collection.** AGT's own programs (HIV,
   phenylketonuria, immuno-oncology) live as corporate pages:
   ```
   GET /wp-json/wp/v2/pages?slug=hiv-aids
   GET /wp-json/wp/v2/pages?slug=phenylketonuria-pku
   GET /wp-json/wp/v2/pages?slug=immuno-oncology
   ```
   Their public URLs are under `/pipeline/`. `list_pages` supports `slug` and `parent` filters, and
   pages are hierarchical via `parent`.

4. **Pull the advisory board.**
   ```
   GET /wp-json/wp/v2/agt_advisors?per_page=100&_fields=id,slug,title,link,content
   ```
   Seven members as of 2026-08-06: Ely Benaim MD; W. David Hardy MD, AAHIVS; Fred Nyberg PhD;
   Jerry Vockley MD, PhD; Dean W. Felsher MD, PhD; Robert Clarke PhD, DSc; John J. Rossi PhD.
   `content.rendered` carries each biography as HTML.

5. **Confirm the shape before you parse.** Every route self-describes:
   ```
   OPTIONS /wp-json/wp/v2/patent
   ```
   returns the accepted arguments (with enums, defaults and bounds) and the item JSON Schema. Use it
   rather than assuming fields — the `acf` field, for example, is present on these types but is an
   empty array on every item checked, so do not build on it.

## Rules

- **Never infer clinical status from this API.** It carries no trial phase, indication, endpoint or
  regulatory-status field for AGT's own programs. The only phase taxonomy on the surface
  (`gene_therapy_phase`) applies exclusively to the four third-party approved therapies. Anything
  about AGT's own clinical progress must be quoted from the news releases or pipeline pages, with
  the source `link` cited.
- Patent titles are not legal status. The collection lists filings AGT chose to publish; it says
  nothing about grant, assignment or maintenance. Do not characterise a patent as granted.
- Decode HTML entities in titles (`Parkinson&#8217;s`).
- All reads are safe GETs. Send no credentials; none are required.
